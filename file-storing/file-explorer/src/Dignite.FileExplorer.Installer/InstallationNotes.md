# Installation Notes for File Explorer Module

Dignite.FileExplorer is a DDD file-management backend (directories, file metadata, a REST API, and
an Angular UI) built on Dignite.Abp.FileStoring's file-upload handler pipeline (size limits, MIME-type
checks, image resizing) over ABP Blob Storing. Installing this module brings in the FileStoring
pipeline as its underlying storage layer.

## Documentation

For structure, usage, and extension points, see the module's own
[README](https://github.com/dignite-projects/abp-modules/blob/main/file-storing/README.md) and
[repository](https://github.com/dignite-projects/abp-modules).
